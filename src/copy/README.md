# MaaTool 文案目录

`zh-CN/` 是当前唯一启用的界面文案源，按业务域拆分。页面和组件可直接导入对应的 `zh-CN/<domain>`，也可通过 `copy.<domain>.<key>` 静态访问。`copy` 是模块命名空间，构建时只保留实际使用的业务域；不要将它展开、遍历或作为完整对象传递，也不要重新聚合所有业务域。

首屏所需的导航标题、页面元信息和加载提示单独维护在 `zh-CN/routes.ts`。这份轻量文案与业务文案互不导入，避免为一个标题或加载提示提前加载完整业务域；修改同名标题时同步核对两处。不要重新写入中文硬编码。

改写前先读 [`PROJECT_BRIEF.md`](./PROJECT_BRIEF.md)，核对产品用途、使用流程、术语和数据处理规则。使用 DeepSeek 或其他文案工具时，也需提供这份简报。

可以改写字符串和长文，以下内容须保持原样：

- 对象 key、文件名和目录结构；
- 模板片段中的插值边界；
- 编码参数、稳定 id、路由、枚举、资源路径和 API 错误码；
- TypeScript 的引号、逗号、括号及 `as const`。

新增语言时复制 `zh-CN` 的模块结构，保留各域的键、参数类型和模块导出约定。当前版本不包含语言检测、切换或回退逻辑。
