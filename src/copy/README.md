# MaaTool 文案目录

`zh-CN/` 是当前唯一启用的界面文案源，按业务域拆分。页面和组件应通过 `copy.<domain>.<key>` 使用文案，不要重新写入中文硬编码。

交给 DeepSeek 或其他文案工具前，先提供 [`PROJECT_BRIEF.md`](./PROJECT_BRIEF.md)。它包含产品定位、用户旅程、术语、品牌语气、安全与第三方边界、禁止杜撰事项、优化优先级及可直接复制的任务提示模板。

交给 DeepSeek 或其他文案工具时，可以修改字符串值和长文内容，但不要修改：

- 对象 key、文件名和目录结构；
- 模板片段中的插值边界；
- 编码参数、稳定 id、路由、枚举、资源路径和 API 错误码；
- TypeScript 的引号、逗号、括号及 `as const`。

新增语言时复制 `zh-CN` 的模块结构，并让组合后的对象满足 `CopyCatalog`。当前版本不包含语言检测、切换或回退逻辑。
