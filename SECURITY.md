# Security policy

Keep unpatched vulnerabilities, credentials, private user data, and production
configuration out of public issues and pull requests.

Use the repository's Security tab to open a private vulnerability report
through [GitHub Security Advisories](https://github.com/ntgmc/goofish-infrast-public/security/advisories/new).
Include the affected commit, reproduction steps, impact, and any proposed
mitigation.

Report bugs that contain no sensitive information through
the [public issue tracker](https://github.com/ntgmc/goofish-infrast-public/issues).
