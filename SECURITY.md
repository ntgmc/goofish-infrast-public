# Security Policy

Please do not disclose an unpatched vulnerability, credential, private user
data, or production configuration in a public issue or pull request.

After this repository is published, use the repository's **Security** tab to
open a private vulnerability report through GitHub Security Advisories. Include
the affected commit, reproduction steps, impact, and any proposed mitigation.

General bugs that do not contain sensitive information may be reported through
the normal issue tracker.
