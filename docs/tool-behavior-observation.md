# 工具操作习惯观测

观测用于后续分析重复操作和入口优化。本轮不新增自动推荐规则，不改变已有
跳过工作台功能的观察期与提醒条件。

记录仅在用户登录且处于有效工具页面时启用，按用户保存在当前浏览器的
`maatool:behavior-observation:v1:<userId>` 中。读取和追加时仅保留最近 30 天，
最多 500 条有效事件；记录不会自动上传。账户设置的“默认进入方式”下提供
折叠的“操作习惯记录”入口，可导出 JSON 或清空这一份操作记录。原工作台
跳过提醒的观察计数和已选择的偏好独立保留。

## 事件与分析用途

| 事件 | 触发点 | 可分析的重复行为 |
| --- | --- | --- |
| `page_visit` | 离开页面、隐藏页面或关闭页面时，记录一段前台可见时长 | 常用栏目、页面往返、前台等待 |
| `profile_open` / `workspace_load` | 工作台打开档案 / 工作区重新加载请求完成 | 反复打开相同档案、切换档案 |
| `data_import` / `data_refresh` | 文件导入、森空岛确认导入或刷新请求完成 | 重复导入、刷新频率和失败重试 |
| `config_save` | 工作区配置保存请求完成 | 配置修改频率、保存失败重试 |
| `preset_save` / `preset_use` / `preset_rename` / `preset_delete` | 保存的配置方案操作请求完成 | 经常使用的方案、重复保存 |
| `schedule_submit` / `scenario_submit` / `job_cancel` | 排班提交、场景比较提交或取消请求完成 | 重复提交、取消后重新提交 |
| `result_select` / `history_config_select` | 点击查看历史结果或使用其配置 | 经常回看的结果、经常恢复的历史配置 |
| `result_load` | 历史结果详情请求完成 | 上述选择是否完成读取 |
| `result_export_maa` / `result_export_full` | MAA 或完整结果导出请求完成 | 常用导出格式、重复导出 |
| `result_archive` / `result_unarchive` / `result_rename` / `result_delete` | 历史结果管理请求完成 | 结果管理频率 |
| `entry_prompt_shown` | 已有入口优化提示显示 | 提示曝光 |
| `entry_enable` / `entry_disable` / `entry_snooze` / `entry_auto_open` | 入口优化选择或自动跳转 | 接受、拒绝、暂缓及启用后的使用情况 |

## 字段和边界

- `name`：上表中固定的事件类别。
- `at`：Unix 毫秒时间。页面事件为该可见区间的开始时间；其他事件为记录时间。
- `session`：当前工具会话的随机标识，用于区分不同标签页的操作顺序。
- `page`：固定的 `dashboard.<栏目>`、`setup.<栏目>` 或 `optimize.<栏目>`，
  不包含完整地址或查询参数。请求事件保留发起请求时的页面。
- `profile` / `subject`：档案或方案、结果、任务的内部标识，仅用于关联重复操作；
  导出时替换为 `profile_1`、`item_1` 等文件内稳定别名。
- `duration_ms`：页面的前台可见时长，或请求从发出到响应解析完成的耗时。
- `outcome`：请求完成、失败或主动取消，分别为 `succeeded`、`failed`、`aborted`。

请求完成只表示接口成功返回并解析，不表示排班任务已完成，也不确认下载文件
已写入用户磁盘。轮询、登录、授权预览和其他未列出的接口不计入。不会记录
UID、昵称、输入文字、配置内容、干员内容、请求或响应正文、错误文本和凭据。

页面进入后台后结束当前可见区间，恢复前台时重新开始；分析停留时长时应按页面
汇总这些区间。事件导出按 `at` 排序。用户退出登录或切换账号后，迟到的请求
响应不会计入新用户的记录。存储不可用时放弃记录，正常操作照常完成。
