# 管理后台 V2 深度重构交付报告

管理后台沿用 V2 的雾白、石板色和铜色主题，按检索、详情、操作与分析组织
页面。现有 `/admin` URL、后端接口、权限模型和业务规则继续使用。

## 页面交付

| 入口 | 页面结构和主要操作 |
| --- | --- |
| `/admin/overview` | 核心指标、趋势和失败分析优先；详细分析、统计范围和报表导出独立呈现 |
| `/admin/users` | 搜索和常用筛选后直接展示记录；高级筛选折叠，选择后显示批量操作；用户详情采用档案索引和单个档案详情 |
| `/admin/cdk` | 默认检索记录；生成 CDK、分布分析独立切换；批量操作在选择记录后出现，生成结果支持复制和下载 |
| `/admin/queue` | 任务监控、服务历史与事件、死信处理分别查看；等待、执行、最近结束局部切换，每次展开一个任务详情 |
| `/admin/risk` | 行为案件、CDK 风险、规则设置分别查看；案件索引对应单个证据详情 |
| `/admin/items` | 保留目录、礼包、新人任务、发放和审计；目录采用道具索引和编辑区 |
| `/admin/invitations` | 奖励规则和邀请统计分别查看；保留道具选择器，重新载入前确认未保存修改 |
| `/admin/registration` | 注册策略、邮件容量、注册邀请分别查看；邀请管理首次访问时加载 |
| `/admin/announcements` | 弹出式公告和全局横幅分别编辑；统一草稿状态与发布栏 |
| `/admin/content` | 保留内容主从编辑、排序和字段定位；统一任务导航与发布状态 |
| `/admin/features` | 按功能组切换配置，集中展示保存状态；停用的计费能力继续受原开关约束 |
| `/admin/setup` 与后台登录 | 统一 V2 主题；管理员账号入口与普通用户维护区分 |

后台导航按运营、权益与发放、服务与安全、站点管理分组。桌面使用侧栏，
小屏使用栏目菜单。导航、主题、页面标题和刷新由后台自己的壳层承接。

## 实现边界

- `src/pages/admin/AdminShell.tsx` 与 `admin.css` 定义后台结构，使用
  `tokens.css` 的 V2 语义映射。页面、对话框、菜单和弹出控件使用同一主题。
- `AdminDashboardView.tsx` 负责会话、可访问栏目与页面装配。总览、用户、CDK
  和风控由独立业务组件承接，配置页复用原有编辑与校验实现。
- 总览数据和 CDK 数据分别由 `overview/useAdminOverview.ts`、
  `cdk/useAdminCdkData.ts` 管理，用户列表继续由 `users/useAdminUserList.ts`
  管理。进入用户页只请求用户数据，操作后刷新相关业务域。
- 用户详情页刷新当前用户；风控案件、CDK 风险和规则使用各自的刷新入口。
  队列离开任务视图或栏目后停止轮询，浏览器隐藏时暂停周期请求。
- 已访问栏目继续挂载并隐藏，保留编辑草稿。首次访问的任务区按需挂载；
  离开对应栏目时关闭通过 Portal 渲染的选择器和未提交操作表单。
- 不新增组件库、状态管理库或表格依赖。后端、数据库与迁移不属于本次后台
  重构的改动范围。

## 操作保护

档案名称、备注、状态和权限修改在一个表单中收集目标、变更内容和操作原因。
提交期间阻止重复提交；失败时保留输入。发生版本冲突后可以刷新目标数据，
更新档案版本，再使用保留的输入提交。档案版本与工作区版本仍分别校验。

重置密码只在有用户管理权限的用户详情中提供。删除用户、清空工作区、
清除绑定、发放、风险复核和高风险操作继续使用原有确认、原因、审计与
认证保护。批量操作继续保留失败项，发放重试继续复用幂等键。

公告本机草稿、线上版本和冲突处理保持原有实现。后续列表刷新失败时，
操作成功提示与刷新失败信息分别呈现。
