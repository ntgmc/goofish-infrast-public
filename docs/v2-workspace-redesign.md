# V2 深度重构交付报告

本轮按用户任务重新组织 V2 页面。`WorkspaceSections.tsx` 接入独立的
`src/pages/v2/pages/` 组件；页面结构与交互由 V2 自己定义。V1 保留原界面，
两代界面共享账号、道具、任务和工具计算的业务 hook。没有新增依赖。

## 实现边界

- 保留雾白、石板色、铜色、字体、间距 token、侧栏、顶栏和明暗主题。
- 新增通用提示、空状态、字段、事实摘要和章节标题组件；样式使用 V2 自有类。
- 专业配置与排班编辑器、森空岛绑定对话框、通知设置、任务进度和对比图表
  继续作为共享控件使用。总览的排班、收益分析、导出和手动编辑保持现有 V2 结构。
- 默认进入方式及其观察记录仍仅属于 V1。V2 根据当前 URL 进入。
- 保留服务开关、权限、有效期、配置保存、草稿离开确认和 API 合约。

## 业务保护与回归

共享 hook 从原页面抽取，原页面继续调用同一实现。配置保存失败时保持当前
账号；添加账号后保留服务返回的新档案 ID，未保存草稿继续由原导航保护处理。
道具数量、容量上限、礼包选择、凭据清除、密码校验及注销流程沿用原规则。
培养条件修改先保留输入，点击更新后应用；切换来源时取消旧请求。

`V2Page.test.tsx` 与 `V2Page.generation.test.tsx` 覆盖账号切换、添加后保存
失败、草稿保护、默认进入偏好隔离、任务提交与恢复，以及历史结果打开。
新 `pages/Inventory.test.tsx` 验证使用失败后保留数量，重试沿用同一个幂等键。
