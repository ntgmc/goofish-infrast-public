## 深度复审发现与修复

深度复审确认 **44 项：1 项 P1、40 项 P2、3 项 P3**。以下问题均已修复；每节的 D 编号只在该模块内有效。

### M01 HTTP 与安全边界

- D01 / P2：连接提前关闭后响应写出挂起。写出前和背压等待中检查连接状态，取消未发送的 Web body，读取期间断连则停止写出。
- D02 / P2：等价 IPv6 代理地址无法匹配。使用原生 URL 规范化 IPv6，统一 IPv4 映射地址并保留 scope；代理信任与 loopback 共用该入口。
- D03 / P3：Expect 默认处理先于应用拒绝。普通请求、checkContinue、checkExpectation 共用边界；拒绝时关闭连接，不先发送 100 或等待正文。

### M03 数据库与迁移

- D01 / P1：回滚失败的连接回池，后续事务可能提交前一次失败写入。回滚失败销毁连接并保留原异常，不重放事务 callback。
- D02 / P2：service file 引号导致真实备份/恢复连接失败。写入 libpq 字面值，拒绝换行与 NUL，保留 0600 权限并移除 IPv6 host 的 URL 括号。
- D03 / P2：CDK 内容丢失仍可通过迁移验证。所有 CDK JSON 参与 checksum，仅归一化已明确迁移的旧 permission/status，保留到期和未知业务字段，并核对关键 typed columns 与 JSON。

### M04 档案、工作区与账号数据

- D01 / P2：清除凭据覆盖并发冻结。使用带归属条件的原子 SQL，只更新当前 binding 的凭据字段及时间，保留状态、权限、备注与绑定身份。
- D02 / P2：改名初始化覆盖刚保存的工作区。复用工作区事务锁，锁内重读，仅初始化仍缺失的工作区。
- D03 / P2：个人数据导出截断方案并遗漏合并源。导出读取全部用户档案及完整 workspace，与界面容量投影分离；仍剔除凭据，保留独立历史导出及 16 MiB 上限。

### M06 排班任务 API 与契约

- D01 / P2：诊断券消费后结果被权限过滤。查询核对服务端预约/消费记录，GET、重放、历史详情及免费预览持久化保留券对应诊断，完整指标和原始结果仍按当前权限限制。
- D02 / P2：取消与完成竞争返回未经投影的结果。取消返回的最新 snapshot 复用当前权限投影。
- D03 / P2：仅轮班制对比被 schema 拒绝。共享 factors schema 与持久化 payload 允许 rotation-only，要求至少一种排班模式。
- D04 / P3：损坏优化器输出误归为可重试故障。加工前校验结果及诊断建议 type/ops，缺 plans/ops 归为不可重试 validation 故障。

### M07 队列、worker 与伸缩

- D01 / P2：不可运行的分析任务阻塞领取。以单次 eligible 候选查询和排序实现公平让行，没有可运行分析任务时直接领取其他任务。
- D02 / P2：取消恢复或中断后任务与预约卡住。中断、租约与硬期限恢复优先结算取消并释放预约；每批最多修复 100 条遗留 queued + cancel_requested，内存 store 同步语义。
- D03 / P2：云响应正文越过超时并占住 leader。deadline 覆盖 JSON 正文读取，中止或损坏正文明确失败，保留实际云 API 错误。
- D04 / P2：关停后迟到领取仍启动执行。线程、inline 和抢占领取返回后复查关停状态，迟到 attempt 归还存储。

### M08 森空岛绑定与导入

- D01 / P2：取消或替换后旧确认仍绑定或扣兑换卡。profile 锁内核对 confirmation ID、stage 与期限；长期卡先锁定并复查 pending，再授权与扣券。刷新保留原无需 pending 的契约。
- D02 / P2：临时 token 错误被误标为凭据失效。复用 envelope 分类，临时故障、缺 token 和损坏正文允许重试，仅明确认证失败标记失效。
- D03 / P2：兑换卡升级重新激活冻结档案。锁内要求目标 active 且未归档，合法升级保留档案 ID。
- M04-D01 关联变体：预览及失效标记锁内读取最新档案，只修改目标字段；失效标记还检查凭据未替换，选择清理按 pending ID 条件更新。不重复计数。

### M09 养成与辅助计算

- D01 / P2：刷取余量未共享，重复刷取并延后完成日期。按已选顺序将产出分配给所有同材料需求，保留干员完成日期、药剂与关卡开放日规则。
- D02 / P2：诊断合成漏算加工龙门币。补齐正式资产中的 100/200/300/400 龙门币费用，删除独立递归消耗实现，复用 allocator 统一处理晋升与加工现金。
- D03 / P3：仓库丢弃已知凭据与超时错误。边界保留已知 client 错误分类，返回重新绑定或重试状态，未知异常仍为通用 500。

### M10 公告与通知

- D01 / P2：Unicode 摘要长度口径不同，合法 emoji 阻止发布。统一 UTF-16 上限，裁剪后移除被截断的高代理字符。
- D02 / P2：旧内容确认将新版通知或公告标为已读。所有 caller 携带展示版本，SQL 条件校验 updated_at，旧版本返回 409；已读版本只向前推进，内容时间至少递增 1 ms。
- D03 / P2：通知分页竞争回填旧游标或卡住加载状态。刷新和已读操作中止旧分页，响应、异常及 cleanup 均按当前 AbortController 归属处理。

### M11 风控、邀请与统计

- D01 / P2：无绑定或过期档案仍激活邀请并发奖。所有入口共用 active、未归档、未过期和关联 CDK 生效条件；被邀请人还需 binding 对象和非空 UID，结算复用同一资格查询。
- D02 / P2：UID 轮换 alias 未合并导致多身份误报。按重叠 alias 传递合并，账号、设备与网络计数共用身份；模型推进至 v1.3.1，沿既有流程重算旧待复核案件。
- D03 / P2：审计预生成时间与提交顺序不同，链产生分叉。链锁内以数据库时间和上一位置 +1 ms 分配单调时间，摘要与持久化使用同一值，业务复核时间仍单独保留。

### M12 管理控制台

- D01 / P2：配置保存响应覆盖后续编辑。功能开关在保存期间 disabled，公开内容编辑器使用原生 disabled fieldset。
- D02 / P2：重登录后旧详情回填，低权限会话显示敏感字段。用户、CDK、干员 loader 共用当前详情 AbortController；重置和卸载中止请求，成功、失败及 finally 核对归属，同管理员重新登录也隔离。
- D03 / P2：撤回忽略预约，任务取消后恢复来源活动的券。grant 锁内检查 reserved；单批次返回 409，活动保留 granted/reversing 后续重试，预约未结算不标完成。退款独立批次继续独立撤回。

### M13 前端外壳
