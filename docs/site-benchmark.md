# 站点对比

V2 的公开页面位于 `/v2/benchmarks`，访客和已登录用户均可从侧栏进入。
本页展示 2026-10-31 冻结的三站测试，统一模拟器为 MaaTool 2.0.1120。
日期、组织者和版本在页面中保留；新批次应使用新的日期目录。

## 数据与公开边界

- `src/data/site-benchmark-2026-10-31.json` 是页面的结果来源，首屏、分类、
  配对收益和搓玉中位数均由这份数据计算。
- `public/benchmarks/2026-10-31/results.json` 与页面数据逐字节相同。
  同目录提供 Markdown、CSV、90 份案例 JSON、ZIP 和 `SHA256SUMS`。
- 案例保留原班次、人员、产品、无人机和菲亚梅塔动作，最终模拟心情、
  日循环结果，以及一图流首次宿舍诊断与精确补位。公开文件采用字段白名单，
  移除账号、档案 ID、任务 ID、查询令牌、登录信息、原始文件名和本地路径。
- 采集工具、完整干员导出和原始任务归档继续本地忽略。公开快照是经整理的
  测试结果；私有计算实现和原始诊断归档仍遵循[开源边界](../OPEN_SOURCE_BOUNDARY.md)。

本地导出工具为 `tools/schedule-benchmark/operations/export_public.py`，
从原始冻结批次和分析结果生成上述文件，先校验两处原始清单，再写出公开产物。
该工具与原始批次不随公开仓库分发。公开仓库的构建和测试只依赖已整理的快照。
更新快照时同时更新页面数据、全部下载文件和校验清单，保留历史目录。

## 读数与交互

执行检查要求心情有效、日循环稳定、安排和动作完整。共同条件逐项确认、
游戏执行与长期供料状态单独保留。失败方案的原始读数继续展示。

243 和右满 252 先统计所有配对的执行结果，仅在双方通过时比较净理智；
±1% 为接近。333 搓玉使用同站同样本较高常规产出作基线，保留基线的执行状态、
碎片材料投入、剩余产出、每玉成本以及赤金和碎片净变化。

筛选支持 `sample`、`layout`、`site`、`status=passed|failed` 查询参数。
“当前筛选直达链接”生成可分享地址；单项链接会自动展开并定位案例。
详细证据在展开时通过公共查询缓存读取，按冻结日期和案例隔离，读取失败可重试。

## 验证

`src/lib/site-benchmark.test.ts` 核对 90 项唯一性、执行数量、完整配对、成本组成、
历史缺项、公开字段边界与全部文件校验和。页面测试覆盖案例直达、筛选、
原排班与诊断切换、证据不匹配和读取重试；V2 集成测试覆盖访客入口和返回导航。

按[验证规范](agent-validation.md)运行页面与路由测试、前端构建、文案、
HTTP、公开导出、架构和 dead-code 检查，并检查桌面、手机与深色模式。
