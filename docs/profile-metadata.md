# 档案默认名称与备注

通过森空岛领取免费档案时，未填写名称则使用“个人排班”，备注默认留空。
名称与备注用于辨认游戏账号；免费或高级权益由权限标签展示。

普通 CDK 升级、终身版兑换 CDK 原地升级时，名称与备注分别判断：

- 名称恰好为“免费个人排班”时，改为“个人排班”。
- 备注恰好为“已绑定森空岛的免费个人排班档案。”时，清空备注。
- 用户自定义内容保留；升级请求显式提交的非空名称或备注优先，显式空备注表示清空。
- 以上修改与升级在同一事务内完成，升级失败不修改名称或备注。

用户可在 V2「账号与档案」编辑名称和备注。

## 已升级档案的一次性修正

工具仅处理 `kind = 'cdk'` 且名称或备注精确匹配上述旧默认值的档案。
它同步更新数据库列与 JSON 记录，不在登录或读取档案时触发。

先在目标环境中预览数量、档案 ID 和逐字段变更：

```sh
node --env-file=.env scripts/repair-profile-default-metadata.mjs
```

审阅预览并按该环境的数据变更流程备份后，执行：

```sh
node --env-file=.env scripts/repair-profile-default-metadata.mjs --apply
```

命令使用 `DATABASE_URL`；已由环境提供时可省略 `--env-file=.env`。
执行时重新读取并锁定匹配档案，所有修改在同一事务内提交；重复执行不会再次修改已清理的记录。
预览可能包含用户自定义名称或备注，应作为内部运维资料保存。
现有数据没有记录默认值来源，用户恰好手填相同文字时也会匹配。
