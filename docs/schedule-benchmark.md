# 三站基建排班测试工作台

工作台用于记录 MaaTool、一图流 V3 和可露希尔基建终端的排班测试。网页离线运行，浏览器本地保存进度，支持 JSON 备份、CSV 和 Markdown 报告草稿。

## 打开工作台

在仓库根目录运行：

```sh
node tools/schedule-benchmark/build.mjs
```

双击生成的 `.cache/schedule-benchmark.html` 即可使用，不需要启动后端。生成文件可以复制到其他电脑。源码位于 [`tools/schedule-benchmark/`](../tools/schedule-benchmark/)。

浏览器如果限制本地文件的存储或 SHA-256 功能，可在仓库根目录运行 `python3 -m http.server 5187 --bind 127.0.0.1 --directory .cache`，访问 `http://127.0.0.1:5187/schedule-benchmark.html`。本地文件与 HTTP 地址使用不同的浏览器存储，请通过 JSON 备份迁移记录。

## 测试流程

1. 打开“协议与环境”，填写抽样种子、候选账号数量、抽样日期和 MaaTool 模拟器版本。
2. 用 P01、P02 试跑，核对三站的设施等级、产物、位置、宿舍等级与氛围，登记配置截图文件名；确认后勾选对应场景。
3. 从后台随机抽取 10 个正式账号，依次登记到 A01—A10。上传后台“下载干员 JSON”得到的数组，工作台保存文件名、SHA-256、已持有数量和精二数量。
4. 每个账号在每个场景下，让三站各生成一次；使用当前练度、完整自动排班，一图流使用深度排班。记录站点版本和生成时间。
5. 登记站点原始方案，在 MaaTool 中执行排班模拟，再导入完整模拟结果 JSON。支持直接结果或 `{ "result": ... }` 包装；MAA 执行 JSON 不包含日产量，不能作为评分文件。
6. 检查完整模拟报告中的心情、占用和容量信息，明确标记“已核对有效”“有效性待确认”“模拟无效”“不支持”或“失败”。导入文件不会自动判定为有效；明确包含心情无效或错误的结果会标记为无效，不能进入有效方案排名。
7. 在“结果汇总”查看各配置成绩，导出 CSV、报告草稿和 JSON 备份。报告包含未完成和异常记录，发布前补充原因分析。

生成与模拟仍在各站和 MaaTool 中完成，工作台不自动提交任务。三站每个组合只生成一次；模拟结果只需导入一次，可复用于全部比较。

## 固定协议

- 2 个试跑账号、10 个正式账号；18 个试跑组合不计入正式汇总，90 个正式组合分别记录。
- 三种场景：243（2 金 2 书）、右满 252（2 金 3 书）、满血 252（2 金 3 书）。贸易站均为两间龙门币。
- 全部采用 12/12/12 小时、36 小时周期，模拟结果必须明确按 24 小时归一化。
- 右满 252 采用 MaaTool 当前 `252` 预设：贸易等级 3/1，制造等级 2/2/3/3/2；满血 252 贸易等级 3/2，制造全部三级。制造站前两间生产赤金。不得将 `252-1` 或其他同名但等级不同的预设混入。
- 允许正常恢复的无人机、已持有且技能解锁的菲亚梅塔、无专精时训练室两个工位、三级回收站；不额外投入储备无人机或回收站加速材料。不人工优化自动生成方案。
- 主指标为净等效理智/日，保留龙门币、经验、赤金产耗与净变化、回收站贡献。估值直接复用 MaaTool 的 `scheduleProductionMetrics` 和 `recyclingSanity`，不复制评分公式。
- 相对提升为 `(MaaTool 得分 - 对照得分) / 对照得分`。超过 +1% 为领先，低于 -1% 为落后，含边界的 ±1% 为接近。此阈值是展示分档，不代表统计显著性或模拟误差范围。
- 分别对照两站，并计算相对两站较优结果的差距。较优比较要求两站结果均有效；缺失一站时仍可查看另一站的单独比较。零或负分母不计算百分比。
- 配置确认、模拟器版本、双方有效结果及一致的估值版本齐全后才计入比较。模拟器版本为批次级记录；不同版本应分别保留批次。
- 三种配置分别汇总 10 个账号的提升中位数、领先/接近/落后数。不将 30 个账号场景当作 30 个独立用户。

## 文件与备份

推荐按 `A01/S1/站点/` 归档干员快照、原始方案、模拟 JSON 和配置截图。工作台记录与备份只包含文件名、哈希、指标和备注，**不包含上传文件原文**。

本地记录依赖当前浏览器及页面地址。清理浏览器、换设备或移动 HTML 前先导出 JSON 备份；在新位置使用“恢复备份”。恢复会替换当前记录，操作前先备份。无法读取已有存储时，工作台暂停自动保存并允许下载原始存储，避免覆盖损坏数据。

HTML 内置构建时的 MaaTool 估值代码及其 SHA-256 指纹。同一批次不能混合估值指纹；更新工作台后，如需继续旧批次，请保留并使用原 HTML 文件。完整模拟报告仍需人工核对，导入提示不能代替可执行性检查。
